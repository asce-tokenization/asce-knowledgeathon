Make your links reviewable.

GitHub

Link to the repository. Include a README with an overview, file map, and setup or inspection instructions. Use a stable release or commit when possible.

YouTube

Link directly to the demonstration video. A public or unlisted video can be reviewed without requesting access. Check playback and the 10-minute limit.

Google Drive

Use a dedicated project folder. Set appropriate viewer access for reviewers and check every file. Keep unrelated or confidential materials out of the folder.

Share only materials you have permission to disclose. If your project cannot be publicly shared, contact the committee for an approved private review arrangement before submission.

Suggested project organization

  • Start hereA README or index with the project title, team, primary pathway, summary, and links to all components.
  • Written materialsProject brief, trust and reuse explanation, ecosystem growth statement, AI disclosure, and ownership note, preferably as PDFs.
  • Artifact and demonstrationThe reviewable files or repository, clear instructions, and the required practical video link.
