# ASCE Engineering Knowledge-a-Thon

Website source for the ASCE Engineering Knowledge-a-Thon: a challenge to turn civil and environmental engineering assets into verifiable, reusable, and governable knowledge products for people and AI systems.

**Target website:** [asce-tokenization.github.io/asce-knowledgeathon](https://asce-tokenization.github.io/asce-knowledgeathon/) — deployment pending verification.

**Contact:** [asce.tokenization@gmail.com](mailto:asce.tokenization@gmail.com)

## Pages

Overview, Participants, Resources, Rules, Project gallery, Updates, FAQs, and Timeline are separate HTML pages. Registration and submission pages connect to the Google Forms. Preparation templates are available under `assets/downloads/`.

## Maintain the website

This is a buildless static website. Keep `index.html` at the repository root and preserve the `assets/` directory structure.

- Edit the relevant HTML pages to update content.
- Edit `assets/css/site.css` for presentation.
- Update public form URLs and approved participant/project entries in `assets/js/config.js`.
- Commit changes to `main`; GitHub Pages publishes the configured source.

Use relative links throughout. Add participant or project details only with permission. Keep response records and organizer credentials outside this repository.
